Orpheon Eclipse Bridge is an independent MySpoti extension.

It is derived from the personal `MySpotiEclipseAddonBridge` extension, with all Eclipse Cloud
account, login, token, premium, Apple Music, Qobuz and Tidal Cloud code removed. The remaining code

download resolution, and a MySpoti settings page.
